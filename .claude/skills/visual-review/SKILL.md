# Visual review

Render the actual surface at representative desktop and mobile sizes. Check:

- clipping and horizontal overflow
- heading rhythm and dense text walls
- code-block wrapping and scroll behavior
- table usability
- contrast and focus states
- terminal output alignment without color
- screenshots against real current output
- optical centering for icons and asymmetric marks

Record viewport, route, browser, and screenshot path. Source review is not a substitute for rendering.
