# Download statistics

Collect source, time window, API query, pagination, and raw response location. Separate GitHub release assets, npm wrappers, containers, Homebrew, Scoop, Winget, or other channels because their counting models differ.

Deduplicate only when the source supports a defensible key. Label estimates and missing channels. Keep reporting factual and avoid equating downloads with active users.
